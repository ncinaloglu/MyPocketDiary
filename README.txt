CEP GÜNLÜĞÜM — KURULUM
1) ZIP dosyasını çıkar. index.html dosyasını bilgisayarında açıp test et.
2) Telefona uygulama olarak eklemek için HTTPS gerekir. GitHub'da yeni herkese açık bir repo aç (örn. cep-gunlugum), ZIP içindeki 5 dosyayı repo köküne yükle.
3) Settings > Pages > Deploy from a branch > main > /(root) > Save.
4) https://KULLANICI.github.io/cep-gunlugum/ adresini telefondan aç.
5) iPhone Safari: Paylaş > Ana Ekrana Ekle. Android Chrome: menü > Ana ekrana ekle/Uygulamayı yükle.

DİKKAT:
- Kayıtlar sunucuda değil, cihazdaki tarayıcı depolamasında tutulur. Cihazlar arasında otomatik eşitlenmez.
- Ayarlar > Yedeği indir ile düzenli yedek alın. Tarayıcı verilerini silmek notları kaybettirebilir.
- Hatırlatma zamanına gelindiğinde uygulama açıkken ve tarayıcı izin verirse bildirim gösterebilir. KAPALIYKEN zamanında push bildirimi garantisi YOKTUR. Bunun için sunucu + web push ya da yerel mobil uygulama gerekir.
- GitHub Pages'a sadece uygulama kodunu yükleyin. Kişisel not yedeğini repoya yüklemeyin.
